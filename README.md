# Vijayalakshmi Forge & Stamping

Static site generated by pure Python. Copy lives in `content.py`, the
generator is `build.py`, checks are `verify.py`. The design brief is
`BRIEF.md`.

    python3 crop.py       # cut images from the company posters (needs build_src/posters)
    python3 build.py      # writes the pages, blog, sitemap, robots, llms.txt
    python3 verify.py     # links, assets, contrast, titles, sitemap
    python3 serve.py      # local preview that serves /about like GitHub Pages
    python3 indexnow.py   # after launch: tell Bing the pages changed

## Writing a blog post

Add a Markdown file to `posts/` (the file name becomes the URL):

    ---
    title: The headline on the page
    date: 2026-11-19
    seo_title: Optional shorter title for the browser tab (under 64 characters)
    description: One or two sentences, 70 to 160 characters, for search results.
    image: p-under-05
    ---
    Paragraphs, ## headings, - lists, 1. lists, **bold** and [links](contact.html).

Then `python3 build.py && python3 verify.py`, push, and after launch
`python3 indexnow.py blog/<file-name>`.

## Search engines and AI assistants

`build.py` writes, on every build:

- `sitemap.xml`: every page with its date.
- `robots.txt`: allows Google, Bing and the AI search crawlers (OpenAI,
  Perplexity, Anthropic, Apple) and points to the sitemap.
- `llms.txt`: a plain summary of the company and its pages for AI assistants.
- `<key>.txt`: the IndexNow key, so `indexnow.py` can ping Bing.
- In every page: canonical URL, Open Graph tags and JSON-LD (Organization with
  certificates and awards, the works as LocalBusiness, breadcrumbs, articles).

While `NOINDEX = True` every page also says `noindex`, so nothing is indexed
before launch.

## Launch checklist (when vijlakforge.com is bought)

1. Add a `CNAME` file containing `vijlakforge.com`; point DNS (four GitHub
   Pages A records for the apex, `www` CNAME to `hari-learns.github.io`);
   set the custom domain in repo Settings, Pages, and enforce HTTPS.
2. In `content.py`: `NOINDEX = False`, `SHOW_PREVIEW_NOTE = False`. Build,
   verify, push.
3. Google Search Console: add the domain (DNS TXT), submit `sitemap.xml`,
   request indexing for the home page.
4. Bing Webmaster Tools: import from Search Console, submit the sitemap.
   Then `python3 indexnow.py`.
5. Google Business Profile for Plant I, Plant II and K.K. Industries, then
   Bing Places (import from Google) and Apple Business Connect.
6. Ask customers for Google reviews with the profile's review link.
