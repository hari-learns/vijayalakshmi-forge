# Vijayalakshmi Forge & Stamping

Static site generated by pure Python. Copy lives in `content.py`, the
generator is `build.py`, checks are `verify.py`.

    python3 crop.py     # cut images from the company posters (needs build_src/posters)
    python3 build.py    # writes the .html pages into the repo root
    python3 verify.py   # links, assets, contrast
    python3 serve.py    # local preview that serves /about like GitHub Pages
